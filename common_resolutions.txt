常见显示分辨率与帧率（EDID/HDMI）
===================================

说明
----
1. “CTA VIC”表示 HDMI/CTA-861 标准视频模式编号，通常比自定义 DTD 更容易被
   机顶盒、游戏机、摄像机和嵌入式 HDMI 信号源识别。
2. “PC/DMT/CVT”表示常见电脑显示时序，通常通过 EDID DTD 或 DisplayID 宣告，
   不一定存在通用 CTA VIC。
3. 23.976、29.97、59.94 等分数帧率通常分别归入 24、30、60 Hz 模式族。
4. 当前 RK3588 HDMI RX 驱动报告的上限为 4096x2160、600 MHz 像素时钟。

五、UHD 4K（3840x2160）
----------------------
分辨率       常见帧率                   CTA VIC/当前程序策略
3840x2160    24/23.976 Hz               VIC 93，原生 RK-UHD 模板
3840x2160    25 Hz                      VIC 94，原生 RK-UHD 模板
3840x2160    30/29.97 Hz                VIC 95，原生 RK-UHD 模板
3840x2160    50 Hz                      VIC 96，YCbCr 4:2:0
3840x2160    60/59.94 Hz                VIC 97，YCbCr 4:2:0

当前 4K50/60 生成策略沿用板卡原生 EDID：通过 YCbCr 4:2:0 Video Data Block
宣告 VIC 96/97，使 594 MHz 像素时钟对应的 TMDS 字符率降到 297 MHz。

当前 set_edid 的 -r 自动生成逻辑尚未为 4096x2160 添加专用 CTA 时序模板。


七、当前程序常用命令
-------------------
./set_edid -r 1280x720@60
./set_edid -r 1920x1080@60
./set_edid -r 2560x1440@60
./set_edid -r 3840x2160@30
./set_edid -r 3840x2160@60

仅生成并查看，不写入设备：
./set_edid -r 3840x2160@60 -n


八、当前生成器实现状态
---------------------
1. 3840x2160@24/25/30/50/60：使用 CTA VIC 93～97 和原生 RK-UHD 模板。
2. 其他 -r 模式：当前使用 CVT-RB 生成 DTD。
3. 2560x1440 及其他高分辨率自定义模式：自动增加 CTA 扩展块，但目标时序
   仍通过 DTD 宣告，不具备通用 CTA VIC。
4. 超过 4096x2160 或超过接收器 600 MHz 像素时钟能力的模式不建议使用。
